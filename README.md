# 无人设备锂离子电池健康评估与剩余寿命预测

> 《Python 数据分析编程》课程项目（题目三）· 第【X】组
> 基于 NASA PCoE 电池老化数据集，完成「数据清洗 → 退化规律 → 容量建模 → 剩余寿命（RUL）预测 → 不确定性量化 → 运维建议」的完整链路。

---

## 1. 项目背景与目标

锂离子电池容量随充放电循环不可逆衰减，且个体差异大、衰减后期加速。运维中「换早了浪费资产、换晚了可能空中断电」。本项目用数据回答两个问题：

1. **一块电池还能用多久**（容量与 RUL 预测）；
2. **这个判断有多可信**（不确定性量化与提前预警）。

核心设定：**只用前 45 个循环建模**，预测第 46—150 循环，模拟「电池刚投运不久就要给出寿命判断」的真实场景。

## 2. 数据

| 项目 | 说明 |
| --- | --- |
| 文件 | `battery_dataset.csv`（636 行 × 4 列，UTF-8） |
| 来源 | NASA PCoE Battery Data Set（B0005 / B0006 / B0007 / B0018，24 ℃ 恒温） |
| 字段 | `battery_id` 电池编号；`cycle` 放电循环序号；`capacity_Ah` 放电容量；`ambient_temp_C` 环境温度 |
| 规模 | 4 块电池，循环数 168/168/168/132，容量范围 1.1538—2.0353 Ah |
| 质量 | 无缺失、无重复；温度为常量 24 ℃（不作解释变量） |

> 若本地保留 NASA 原始 `.mat` 文件，脚本会自动合并放电时长、温度、电压、能量、内阻等辅助特征；无 `.mat` 时仅使用容量派生特征，主结论不变。

## 4. 环境与运行

```bash
# 1) 安装依赖
pip install -r requirements.txt

# 2) 运行（数据放在脚本同级目录）
python battery_health_analysis.py
```

输出：

- `battery_cycles.csv`：清洗后的逐循环数据（含 SOH、是否再生尖峰）
- `figures/fig1_degradation.png` … `fig7_ml_rul.png`
- `analysis_results.json`：指标汇总
- `battery_health_report.html`：网页版报告

复现约定：GP 优化、后验抽样均固定随机种子（42 / 11 / 3），报告中的数字可逐项复算。

## 5. 主要结果

| 环节 | 结论 |
| --- | --- |
| 退化规律 | 先缓后急；全周期衰减速率 2.79—5.06 mAh/循环（差 1.8 倍）；跌破 80% SOH 的循环数 44.7—85.1（差约 1.9 倍） |
| 数据清洗 | 5 点滑动中值 + 0.06 Ah 阈值，替换 4 个容量再生尖峰，未删除任何循环 |
| 容量建模 | 对数 GP 最优：RMSE 0.1124 Ah、MAPE 6.69%；但三种方法在 46—150 循环的 R² 全为负 |
| RUL 预测 | 二次回归中位绝对误差 6.7 循环（最优）；对数 GP 在 B0005 高估 58.4 循环、B0007 无交点 |
| 不确定性 | GP 后验 1500 次抽样；提前预警 95% 区间覆盖 13/15（86.7%），区间宽度 12.3—184.2 循环 |
| 跨电池迁移 | 梯度提升留一验证平均 MAE 20.0 循环；B0006 折 R² 为负 → 通用模型只能作冷启动 |

对照图见 `figures/` 与项目报告第 4—6 章。
