# 02 清洗与探索

对应报告第 3—4 章，代码位于 `battery_health_analysis.py` 的 `clean_capacity()` 与 `main()` 前半部分。

## 1. 处理原则：最小干预

电池退化数据是「单调下降趋势 + 随机波动 + 真实的容量再生」的叠加。过度清洗会抹掉有物理意义的信号，使后续建模过度乐观。因此能保留的记录一律保留，只对确有证据的异常做局部修正。

## 2. 容量再生尖峰

**现象**：曲线中段出现 1—2 次「回升—回落」，形态为向上的尖峰。

**成因**：静置或小电流后，部分被捕获的锂离子重新参与反应、SEI 膜局部破裂重建，使下一次放电可测容量短暂回升。既不是测量错误，也不是健康恢复。

**为什么不用 3σ / IQR**：容量是强趋势序列，均值与标准差随循环漂移；全局阈值会把整段后期低容量数据误判为异常（实测 3σ 会大量误删、IQR 同样失效）。

**采用方案**：

```
med(k)  = capacity_Ah 的 5 点居中滑动中值
if |capacity_Ah(k) - med(k)| > 0.06 Ah:  capacity_clean(k) = med(k)
否则保持原值；替换后线性插值
```

阈值 0.06 Ah ≈ 额定容量（2.0 Ah）的 3%。四块电池最大偏差为 0.058 / 0.079 / 0.073 / 0.060 Ah，阈值过高会漏检、过低会抹平正常波动。

## 3. 清洗结果

| 电池 | 原始循环数 | 替换的再生尖峰 | 最大偏差(Ah) | 处理 |
| --- | --- | --- | --- | --- |
| B0005 | 168 | 0 | 0.058 | 无需处理 |
| B0006 | 168 | 2 | 0.079 | 局部中值替换 |
| B0007 | 168 | 1 | 0.073 | 局部中值替换 |

**验证**：清洗后容量与循环序号的相关系数为 −0.988 / −0.982 / −0.989 / −0.970，趋势完整；尖峰处由突变变为平缓波动。

## 4. 特征构造

| 特征 | 定义 | 用途 |
| --- | --- | --- |
| `capacity_clean` | 清洗后容量 | 建模目标 |
| `soh` | capacity_clean ÷ 前 5 循环均值 | 统一不同初始容量个体的刻度 |
| `roll5` | 5 循环滚动均值 | 抑制循环波动 |
| `slope10` / `slope20` | SOH 在 10/20 循环内的平均变化 | 刻画近期衰减速度，ML 主特征 |
| `energy_Wh` | ∫U·|I|dt ÷ 3600 | 放电能量，贴近实际续航 |
| `r0_ohm` | 初始瞬时压降 ÷ 电流 | 内阻代理量 |

## 5. 探索结论

1. **先缓后急**：前 40—50 循环平缓，100 循环后加速；中段有再生造成的锯齿。
2. **差异随时间放大**：初始容量最大最小相差约 0.18 Ah，第 150 循环时超过 0.3 Ah。
3. **早期即可辨识快慢**：第 45 循环 SOH 为 95.4% / 86.1% / 95.5% / 86.7%，快慢两类相差近 3 倍。
4. **三个反直觉现象**：初始容量高 ≠ 长寿（B0006）；循环数少 ≠ 健康（B0018）；末期 SOH 差异小于循环数差异。
