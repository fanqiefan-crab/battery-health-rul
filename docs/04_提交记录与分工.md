## 2. 提交规范

- 格式：`<type>(<scope>): <摘要>`，type ∈ {feat, fix, docs, refactor, chore}，scope ∈ {repo, data, clean, model, eval, report}；
- 一次提交只做一件事，正文写清「改了什么、对应报告哪一节、谁负责」；
- 不提交运行产物（见 `.gitignore`），保证仓库轻量可复现；
- 提交版本打标签 `v1.0`。

## 4. 重建与推送

```powershell
# 1) 安装 Git：https://git-scm.com/download/win
# 2) 在项目根目录运行（会删除已有 .git 并重建，谨慎）
powershell -ExecutionPolicy Bypass -File _work\git\git_setup.ps1 -Force

# 3) 查看结果
git log --graph --pretty=format:'%h %an %s' --all
```

推送至 GitHub（一条命令）：

```powershell
# 先在 https://github.com/new 新建空仓库（不要勾选 README）
powershell -ExecutionPolicy Bypass -File _work\git\push_to_github.ps1 -User 【GitHub用户名】
```

脚本会配置 remote、推送 main 与 v1.0 标签；首次推送弹出浏览器登录 GitHub，登录一次即可。
也可以手动执行：

```bash
git remote add origin https://github.com/【用户名】/battery-health-rul.git
git push -u origin main
git push origin v1.0
```

首次 push 需使用 PAT（Settings → Developer settings → Personal access tokens）或 SSH key；不要把令牌写进仓库。
